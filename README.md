# Code for the paper “Unoriented 3D Line Registration by Absolute Gram Matching in One Dimension Up Geometric Algebra”

This repository, [`3D_Lines_Unknown_GA`](https://github.com/harismats/3D_Lines_Unknown_GA), provides notebooks, Python source and supplementary videos for the paper. The experiments use synthetic scenes to evaluate absolute Gram matching, orientation recovery and pose estimation for three dimensional lines with unknown correspondences.

The repository contains the code and the four videos in [`media/`](media/). Figures, tables, numerical results and generated result archives are produced by running the code and are not stored in this repository.

## Notebooks and Python files

The experiments are run in Google Colab using Jupyter notebooks (`.ipynb`). The equivalent Python files (`.py`) are also provided for inspection and local execution.

| File | Purpose |
| --- | --- |
| [`AACA_Full_Study.ipynb`](AACA_Full_Study.ipynb) | Main Colab notebook. Runs the complete synthetic registration study, including validation, ablations, comparison methods, sequential experiments and video generation. |
| [`AACA_Full_Study.py`](AACA_Full_Study.py) | Python companion to the main notebook, containing the same study modules and execution sequence. |
| [`ga_line_registration_gram_reproducible_rev12.py`](ga_line_registration_gram_reproducible_rev12.py) | Geometric algebra representation, absolute Gram matching, orientation recovery, pose refinement and the proposed method's experiments. |
| [`line_registration_baselines.py`](line_registration_baselines.py) | Comparison methods based on random sample consensus and compatibility graph matching. |
| [`line_registration_comparison_study.py`](line_registration_comparison_study.py) | Comparative experiments, calibration, fixed correspondence pose comparisons and their plots. |
| [`verification/minimv_vs_clifford_comparison.py`](verification/minimv_vs_clifford_comparison.py) | Separate comparison of the compact algebra implementation with the Python `clifford` package. It can also be run in its own Colab notebook. |
| [`requirements.txt`](requirements.txt) | Dependencies for running the main study locally. |

The main notebook and its Python companion write and execute the three study modules, which are also provided separately for inspection.

## Run the study

### Google Colab

1. Open [`AACA_Full_Study.ipynb`](AACA_Full_Study.ipynb) in [Google Colab](https://colab.research.google.com/) by selecting **File → Open notebook → GitHub** and pasting this repository's URL, or by uploading the notebook.
2. Select **Runtime → Run all** and allow the complete sequence to finish.
3. Download any generated outputs that you want to keep before ending the Colab session.

No external dataset or GPU is required. Running the code creates figures, tables, numerical measurements, calibration records, checks and videos in `GA_1DUp_Gram_Line_Registration_Results/`, together with a results archive. These outputs remain local or in Colab and are not uploaded to this repository. A rerun replaces that output directory, so save anything you want to keep first. Fixed seeds reproduce the synthetic scenes, while timings can vary between machines.

### Local Python

Using Python 3.12, install the dependencies and run the companion file from the repository root:

```bash
python -m pip install -r requirements.txt
python AACA_Full_Study.py
```

## Comparison with the Python clifford package

The recorded study uses a compact custom implementation of the small subset of geometric algebra operations needed by the calculation. The [comparison script](verification/minimv_vs_clifford_comparison.py) compares it with the Python [`clifford` package](https://clifford.readthedocs.io/) using basis blade products, random multivector operations and a rotor action, with absolute coefficient tolerance `1e-12`. This tests algebraic agreement rather than speed.

Use a separate Colab runtime for this check, because installing `clifford` in the study environment can change its selected algebra backend and timings. Upload the comparison script to that runtime, then run:

```python
%pip install clifford numpy pandas ipython
%run minimv_vs_clifford_comparison.py
```

Inspect the final comparison summary and retain the printed package versions when documenting a successful check.
